## Thread 扩展结构

1. Hook：结果、可信度和阅读收益。
2. 原问题：具体说明旧流程的摩擦。
3. 核心判断：为什么需要路由而非一味提速。
4. 快速路径：适用条件与流程。
5. 严格路径：硬性排除项。
6. 实验设计：基线、场景数和运行次数。
7. 结果：只写证据支持的数字。
8. 限制：样本、遥测和泛化边界。
9. 下一步与提问。

## 发布前检查

- [ ] Hook 在前两行，且含具体信息。
- [ ] 单帖或 Thread 的每一条均不超过 280 字符。
- [ ] 主帖没有外部链接；链接位于第一条回复。
- [ ] 中文和英文没有混在同一条内容中。
- [ ] 只有 0–1 个自然 hashtag。
- [ ] 图片中的数字与正文完全一致。
- [ ] 所有结论能在事实卡或报告中找到证据。
- [ ] 明确写出重要实验限制。
- [ ] CTA 鼓励真实讨论，不诱导垃圾互动。
