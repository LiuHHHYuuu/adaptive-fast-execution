# 本地发布模板

这些模板不调用任何平台 API，也不需要密钥。复制模板、填写同一份事实卡，再把最终内容手动粘贴到平台即可。

## 推荐流程

1. 先填写 `source-brief.yaml`，锁定事实、证据和不能宣称的内容。
2. X 使用 `x-post-template.md`：正文不放外链，仓库链接放第一条回复。
3. 小红书使用 `xiaohongshu-post-template.md`：封面给结果，正文讲问题、方法、证据和限制。
4. 发布前逐项完成模板底部检查清单。
5. 发布后把 URL 和数据记录回模板，方便复盘。

`examples/` 中已经放入 Adaptive Fast Execution 项目的可直接修改版本。

## 后续视频扩展

未来可以从同一份 `source-brief.yaml` 派生：

- 抖音：30–60 秒竖屏脚本、镜头表、字幕和封面标题。
- YouTube Shorts：英文/中文短视频脚本。
- YouTube 长视频：Hook、章节、演示镜头、B-roll、字幕与简介。

这样事实源只维护一次，不同平台只改变叙事和格式。
