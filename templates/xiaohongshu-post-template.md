## 标题候选（选择一个）

1. `[结果数字]：我是怎么解决[具体问题]的`

## 图片顺序

1. 封面：冲突 + 核心数字。
2. 问题：旧流程为什么拖慢小任务。
3. 双路径图：快速模式与严格模式。
4. 快速模式判定条件。
5. 严格模式硬边界。
6. 实验设计与对照基线。
7. 结果与限制。
8. GitHub 搜索词或项目名；如平台允许，再放链接。

## 发布前检查

- [ ] 标题没有绝对化、收益保证或未验证百分比。

- [ ] 封面和正文数字一致。
- [ ] 图片没有密钥、私人路径、账户信息或内部日志。
- [ ] 清楚写出样本量和重要限制。
