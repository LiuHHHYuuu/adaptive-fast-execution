# Mandatory Brainstorming Baseline

Before any creative or implementation work:

1. Inspect project context.
2. Ask clarifying questions one at a time.
3. Propose two or three approaches.
4. Present a design and wait for user approval.
5. After approval, write and commit a design document.
6. Ask the user to review the written specification and wait again.
7. Only after that review, write an implementation plan.
8. Do not implement until all design and review gates are complete.

This gate applies even to small or apparently simple tasks. Do not treat a task as too simple to need design.
